Local only

No network requests and no telemetry. A request allowlist, a strict Content-Security-Policy, and lint rules that ban network APIs enforce it. The optional receiver for Claude Code's cost reports is off until you turn it on, and it listens only on 127.0.0.1.

Read-only

Beekeeper never writes to ~/.claude or to your repositories. Every git command it runs is checked against an allowlist of read-only ones.

Your data stays put

Transcripts are read in place and shown as plain text. What beekeeper keeps is its own, in its app data folder and never sent anywhere: a cache of your session lists, project totals, and daily usage that expires after 7 days; an archive of your sessions, such as their agents, tokens, costs, and touched file paths (the full detail once a session has been quiet for 7 days), with no expiry, so it outlives Claude Code's own transcripts; and a few settings. It never stores prompts, responses, tool output, or file contents. To remove the archive, quit beekeeper and delete archive.sqlite, archive.sqlite-wal, and archive.sqlite-shm.
