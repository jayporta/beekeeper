Three promises

Local only

No network requests and no telemetry. A request allowlist, a strict Content-Security-Policy, and lint rules that ban network APIs enforce it. The optional receiver for Claude Code's cost reports is off until you turn it on, and it listens only on 127.0.0.1.

Read-only

beekeeper never writes to ~/.claude or to your repositories. Every git command it runs is checked against an allowlist of read-only ones.

Your data stays put

Transcripts are read in place and shown as plain text. beekeeper keeps only a cache of your project and session lists, in its own app data folder, and no cached list lives longer than 7 days.
